# Unreal Island – Final Prototype Project

**Unreal Island** is a final project I created for a game prototyping course. It serves as a technical demonstration to explore various tools and systems available in the Unreal Engine editor.

---

##  Project Overview

The project features a custom island built using the **Landscape** tool. To populate the environment, I used **Procedural Foliage** and integrated the **Water System** for a more dynamic and immersive world.

While my main focus in this course was on **Chaos Destruction** in a first-person gameplay setting (e.g., shooting destructible cubes), this island also showcases a destructible **statue** that shatters into pieces at the start of the scene.

---

##  Features Demonstrated

-  **Procedural Foliage**: Auto-generated vegetation for the island terrain.
-  **Water System**: Interactive water elements for lakes and shores.
-  **Chaos Destruction**: A destructible statue as part of the level intro.
-  **Cloth Simulation**: A flag waving in the wind demonstrates cloth physics.
-  **Motion Matching**: Imported and implemented motion matching for realistic, high-quality character animations.
-  **Day-Night Cycle**: My personal touch — a full dynamic day and night cycle, allowing experimentation with lighting and atmosphere.

---

##  Technologies Used

- Engine: **Unreal Engine 5**
- Systems: Chaos, Niagara, Landscape, Water, Foliage, Animation Blueprint, Lighting

---

## Status

 **Completed Demo** – This project is finished as a standalone tech demo and learning experience. It’s not a full game, but a showcase of different Unreal Engine features working together.
